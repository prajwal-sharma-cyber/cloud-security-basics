# Cloud Security Basics

A beginner cloud-security architecture project covering identity, least privilege, network controls, logging, encryption and secure configuration.

## Scenario
A fictional organisation hosts a web application and database in the cloud.

## Architecture
```text
Internet
   |
Load Balancer
   |
Application Tier
   |
Database Tier

Security Services:
IAM | Logging | Monitoring | Key Management | Backup
```

## Core Controls
### Identity
MFA, least privilege, role-based access and separate admin accounts.

### Network
Private database access, security groups/firewall rules and restricted management access.

### Data
Encryption in transit and at rest plus key-management controls.

### Monitoring
Centralised logs, alerting and audit trails.

## Skills
Cloud security concepts, IAM, network security, encryption and monitoring.
